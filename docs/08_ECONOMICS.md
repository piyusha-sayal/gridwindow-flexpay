# 08 — Economics (synthetic assumptions)

Every number below is a **labeled synthetic assumption** used for a sandbox demo. None is a real utility tariff, a real PayPal fee quote, or a measured operating cost. Source: `src/domain/economics.ts`, `src/domain/forecast.ts`.

## Assumptions

| Parameter | Value |
|---|---|
| List price (immediate charging) | 56 ¢ per **battery** kWh |
| Charging efficiency | 92 % (grid kWh = battery kWh / 0.92) |
| Assumed payment fee | 3.49 % + 49 ¢ (assumption; not a PayPal quote) |
| Operating cost | 120 ¢ per session |
| Driver share of modeled energy saving | 50 % |
| Minimum driver discount | 25 ¢ |
| Minimum operator improvement | 1 ¢ |
| TOU energy price (local time) | 00–06: 14 ¢/kWh · 06–16: 24 ¢ · 16–21: 46 ¢ · 21–24: 30 ¢ |
| Congestion surcharge | +35 ¢/kWh on site load above 70 % of the 33 kW cap |

## Rules

1. Baseline = **immediate** charging, which must itself be feasible for the same port, energy and deadline. If not, no savings are claimed and no offer is made.
2. Energy cost = Σ slot grid-Wh × (TOU + attributable congestion surcharge), rounded **up** to cents.
3. Driver discount = ⌊50 % × (baseline energy cost − flexible energy cost)⌋.
4. An offer is published only if discount ≥ 25 ¢ **and** operator contribution (price − fee − energy − operating cost) improves by ≥ 1 ¢ **and** price ≤ driver's spend cap.
5. The independent validator `validateOfferEconomics` recomputes fees/contribution from scratch before acceptance.

## Worked example (real engine output)

Generated by `node_modules/.bin/tsx scripts/sample-economics.ts` (night 2026-10-20, seed 42, port A, plug-in 19:00, depart 07:00, 30 kWh battery target).

| | Immediate baseline | Flexible "Lowest-cost window" |
|---|---|---|
| Charging window | 19:00–22:00 | 00:00–03:00 |
| Grid energy | 32.625 kWh | 32.625 kWh (≥ 30 / 0.92 = 32.609; 25 Wh step overshoot) |
| Battery energy | ≥ 30.0 kWh | 30.015 kWh |
| Modeled energy cost | $13.31 | $4.57 |
| Price to driver | $16.80 (list) | **$12.43** (discount $4.37) |
| Assumed fee | $1.08 | $0.93 |
| Operating cost | $1.20 | $1.20 |
| Operator contribution | $1.21 | **$5.73** (+$4.52) |

Both conditions hold: driver pays $4.37 less; operator's modeled contribution rises $4.52. A second offer ("Gentle half-power charge", 00:00–06:00 at ≤ 5.5 kW) prices identically in this scenario; "Ready 1 hour early" was rejected as a duplicate schedule.

Counter-example (also tested): plug-in 01:00, depart 04:00 → the whole window is already cheap, so **zero** flexible offers are returned (`NO_ENERGY_SAVINGS`).

## Physics reference checks (unit tested)

- 30 kWh battery in 3 h at 11 kW / 92 %: 12 slots × 2.75 kWh = 33.0 grid kWh → 30.36 battery kWh → **feasible**.
- Same at 7.2 kW: 21.6 grid kWh → 19.872 battery kWh → **infeasible**.
